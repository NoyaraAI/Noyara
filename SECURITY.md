# Security Policy

## Reporting a vulnerability

Do not open a public issue. Use [GitHub private vulnerability reporting](https://github.com/NoyaraAI/Noyara/security/advisories/new) and include the affected version, impact, and reproduction steps. Remove credentials and personal data.

The maintainers will acknowledge the report within five business days and coordinate remediation and disclosure. Supported releases are the latest production release on `main`.

Repository administrators should enable GitHub Secret Protection with push protection, CodeQL, Dependabot alerts, and branch protection for `main`.
